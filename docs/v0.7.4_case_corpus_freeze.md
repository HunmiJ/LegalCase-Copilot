## Main corpus

主语料仅包含：

- 人民法院案例库真实官方案例；
- 通过 `ELIGIBLE_MAIN_CORPUS` 资格审查；
- `source_url` 可追溯至人民法院案例库官方详情页；
- 具有非空、可审计的原始 `raw_text`。

主语料进入 `data/processed/cases/cases.jsonl`、BM25 corpus 和 case semantic embedding index。

## Reproducibility

Case IDs 使用官方入库编号或稳定 deterministic identity。主语料、embedding 和 embedding index 的 case ID 集合必须一致；原始 PDF 只读保存。后续在本冻结 corpus 上进行检索评测，不使用 LLM 生成或补造案例字段。
