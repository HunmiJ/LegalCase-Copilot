# V0.6 Context Depth Decision

本次实验仅比较同一批 6 条 in-domain real smoke query 的 Reranker Top 5 与 Top 8 RAG context。两组使用相同的 DeepSeek provider、generation prompt、schema、citation validator 和 retry policy；没有修改 retrieval benchmark、原始 DOCX 或 citation safety 规则。

## 实验结果

| 指标 | Top 5 | Top 8 |
|---|---:|---:|
| Retrieval coverage | 0.8333 | 1.0000 |
| Generation success rate | 1.0000 | 1.0000 |
| Retry rate | 0.3333 | 0.0000 |
| Fallback rate | 0.0000 | 0.0000 |
| Citation validity | 1.0000 | 1.0000 |
| Grounded claim rate | 1.0000 | 1.0000 |
| Unsupported citation rate | 0.0000 | 0.0000 |
| Average generation latency | 26366.99 ms | 16457.98 ms |
| Average total latency | 37574.98 ms | 27720.31 ms |
| Average context | 5 articles / 1112 chars | 8 articles / 1839 chars |

## 决策

默认 RAG context 从 Top 5 调整为 **Top 8**。

依据用户预设优先级：Top 8 的法律依据覆盖率从 0.8333 提升至 1.0000；citation safety 和 grounded claim rate 没有恶化；生成成功率保持 100%，fallback 为 0，且本次实测重试率从 0.3333 降至 0；平均总延迟反而下降约 9.85 秒。虽然 context 字符数增加，但本次真实实验未显示生成或延迟成本恶化。

完整脱敏逐 query 结果见 `evaluation/results/v0.6_real_context_depth_comparison.json`。该文件不包含 API Key、请求头或原始 provider 响应。
