# V0.7.1B Official Case Retrieval Feasibility Audit

日期：2026-08-20

## 结论

**V0.7 OFFICIAL RETRIEVAL FEASIBILITY: PASS**

结论是“可合规设计并保留 fallback”，不是“已经具备稳定自动抓取能力”。本阶段未实现爬虫、网页解析、私有 API 调用或案例下载。

## 合规 retrieval strategy

| 策略 | Feasibility | 稳定性 | 登录 | 页面变化影响 | Production / Demo |
|---|---|---|---|---|---|
| A. 官方公开 API | 当前不可用 | 若未来有文档 API，则高 | 取决于官方授权 | 低 | 当前不可用；未来最适合 production |
| B. 官方网页公开搜索 | 可人工/低频使用 | 中 | 可能需要登录或受限 | 高 | Demo 可用；production 需官方许可和限流 |
| C. 官方页面 URL fetch | 对已确认 URL 可行 | 中高 | 多数公开详情页无需登录 | 中 | 适合受控详情页读取和人工核验 |
| D. 外部 Web Search + domain restriction + official fetch | 可行 | 中 | 外部搜索不等于官方检索授权 | 中高 | 适合发现候选；最终必须回到官方页核验 |
| E. 本地 curated corpus fallback | 当前最稳定 | 高 | 不需要 | 低 | 最适合可复现 demo、benchmark 和离线运行 |

## Provider interface

已新增 `backend/cases/sources/` 接口层：

- `base.py`：`CaseSourceProvider`、`CaseSourceSearchRequest`、`CaseSourceResult` 和 official→local fallback policy
- `local.py`：本地 curated corpus provider contract
- `supreme_court.py`：最高法官方来源 provider contract
- `people_court_library.py`：人民法院案例库 provider contract

统一结果字段为：

`title`、`database_case_number`、`case_number`、`case_type`、`basic_facts`、`case_gist`、`source_name`、`source_url`、`retrieved_at`。

三个官方 provider 当前明确抛出 unavailable，不执行不可靠网络访问。

## Fallback 与 cache 设计

```text
Official Search available
  → official provider
  → normalize
  → canonical deduplicate
  → return

Official Search unavailable
  → curated local provider
  → return local results
```

未来 runtime cache 只能保存已确认官方来源的结果，并至少保留 `source_url`、`retrieved_at`、`source_name`。未经人工/规则确认的网页内容不得写入正式 corpus。

三类数据必须隔离：

1. `curated corpus`：人工审核后进入 `data/processed/cases/` 的本地案例。
2. `benchmark corpus`：固定评测案例与标注，不随运行时搜索变化。
3. `runtime cache`：可失效、可清理的官方检索结果缓存，不自动晋级为 corpus。

## 架构比较与推荐

| 方案 | 简历价值 | 稳定性 | 可评测性 | 开发成本 | 维护成本 | 可追溯性 |
|---|---|---|---|---|---|---|
| A. 全本地数据库 | 高 | 高 | 高 | 中 | 中高 | 高 |
| B. 全实时官方搜索 | 高 | 低到中 | 低 | 高 | 高 | 高但依赖在线状态 |
| C. Local + Official Hybrid | 最高 | 高 | 高 | 中高 | 中 | 高 |

推荐 **C. Local + Official Hybrid**：用 3 个已审核案例作为稳定 curated corpus，官方检索作为受控增强来源，统一 normalize/deduplicate，官方不可用时自动回落本地。这样既展示可追溯的数据工程，又不会把演示和 benchmark 绑定到不可控的登录、页面结构或网络状态。
