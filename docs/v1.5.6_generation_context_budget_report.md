# V1.5.6 Generation Context Budget Optimization Report

## 实施内容

- 上游 BM25、semantic、hybrid、reranker 检索深度保持不变。
- 送入 generator 的默认法规 context 改为 Top3。
- 案例增强 context 改为最多 Top2。
- generation context 增加3500字符预算。
- `basic_facts` 增加240字符安全截断预算；保留 title、court、date、dispute_focus、judgment_result、legal_basis。
- LAW 文本、CASE citation ID 和 CASE 法律依据/裁判结果不做随机截断；预算不足时优先保留法规，随后保留案例争点、结果和法律依据，最后才省略案例事实。
- retry 反馈改为短结构化错误，不重复堆叠完整 validator 错误。
- citation validator 安全标准未降低，不存在的 citation 仍然拒绝。

## 真实5条 smoke 对比

| 指标 | V1.5.5 smoke | V1.5.6 smoke |
|---|---:|---:|
| law-only generation success | 0.4 | 0.2 |
| law+6492-cases generation success | 0.2 | 0.0 |
| 成功响应 citation validity | 1.0 | law-only 1.0；增强模式无成功响应 |

V1.5.6 smoke 的最终失败分布：

- law-only：2 次 `unsupported_citation`，2 次 `generation_failed_after_retries`，1 次成功。
- law+6492-cases：1 次 `unsupported_citation`，4 次 `generation_failed_after_retries`，0 次成功。

`unsupported_citation` 仍表示安全校验拒绝；本轮未通过放宽 validator 或自动映射解决。生成成功率未提升，说明在当前样本和 provider 波动下，单纯缩短 context 尚不足以稳定增强生成。

## 测试结果

- 完整 pytest：`157 passed, 1 warning`
- 针对 generation budget、citation namespace、真实生成解析：`16 passed, 1 warning`
- 未运行完整30条真实评测。

## 结论与建议

当前不建议进入完整30条真实评测。建议先继续保持 Top3 laws + Top2 cases 的预算策略，并增加下一阶段诊断：分别记录 provider timeout、模型输出的具体 citation/条号错误，以及每个案例字段裁剪前后的生成结果。任何后续优化都应继续保留严格 citation validator，不能将失败响应标记为成功。
