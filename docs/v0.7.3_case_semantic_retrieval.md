# V0.7.3 Case Semantic Retrieval

本阶段实现本地 `BAAI/bge-small-zh-v1.5` Case Semantic Retrieval。

当前 curated corpus 仅包含 3 个真实案例。因此本阶段只能证明 embedding、索引、语义搜索和 provenance 保留链路工作，不能证明模型在大规模真实案例库上的准确率。

本阶段不生成或宣称正式 Recall@K、MRR 等 benchmark，不实现 Hybrid、Reranker、网页抓取或案例 Embedding 以外的智能生成能力。

## Embedding 内容

向量文本由以下字段构造：

`title + keywords + basic_facts + dispute_focus + case_gist`

`judgment_result` 和截断后的 `court_reasoning` 作为轻量补充。`source_url`、`source_file`、`retrieved_at` 不参与 embedding。

## 文件

- `data/processed/cases/case_embeddings.npy`
- `data/processed/cases/case_embedding_index.json`
- `backend/cases/search/semantic.py`
- `scripts/search_cases_semantic.py`

统一搜索支持 `mode="bm25"` 和 `mode="semantic"`；默认仍为 BM25。`mode="hybrid"` 仅预留，尚未实现融合。

后续需扩大 curated corpus 后，再建立人工标注的 Case Retrieval benchmark。
