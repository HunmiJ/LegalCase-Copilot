# V0.7.5 Formal Case Retrieval Benchmark

本评测冻结当前 19 条 main curated case corpus，并使用 30 条人工设计、先于检索运行冻结的劳动争议自然语言 query。辅助案例 011 不属于正式 corpus，也不进入 relevant labels。

## 评测对象

- BM25：现有本地案例 BM25 检索。
- Semantic：现有 `BAAI/bge-small-zh-v1.5` 案例语义检索。

本阶段不修改检索算法，不使用 LLM、Query Expansion、Hybrid、RRF 或 Reranker。

## 标注与指标

每条 query 的 `relevant_case_ids` 与 `primary_case_id` 依据冻结案例正文人工标注，不能根据检索结果回填。报告 Recall@1/3/5、MRR、nDCG@5；MRR 取 Top 10 内首个 relevant case 的倒数。多 relevant query 的 nDCG 使用理想相关数量归一化。

难度分组为 easy/medium/hard，约为 10/12/8；query 类型为 fact paraphrase、legal issue、ambiguous_difficult。

## 结果解释边界

这是 19 条 curated cases 上的首个正式功能 benchmark。指标可以比较当前两条本地检索路径，但不能外推为大规模人民法院案例库准确率。结果文件同时记录 query SHA-256、每条 Top 10、分类、延迟和代表性失败/分歧。

## 可复现运行

```powershell
python evaluation/evaluate_case_retrieval.py
pytest -q
```

`case_retrieval_queries.sha256` 用于检测 benchmark query 是否被修改。正式评测输出为 `evaluation/case_retrieval_results.json` 与 `evaluation/case_retrieval_metrics.json`。
