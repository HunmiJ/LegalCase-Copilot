# V0.7.6 Hybrid Case Retrieval

本阶段在冻结的 19 条 main case corpus 与 30 条 V0.7.5 benchmark 上比较 BM25、Semantic 和 Hybrid。frozen corpus、query、relevance labels 与 BGE embedding 不修改。

## 方法

Dev/Test 采用 seed=42 的 deterministic stratified split：Dev 20、Test 10，按 easy/medium/hard 分层。所有 RRF k（20/40/60/80）和 weighted semantic alpha（0.6/0.7/0.8/0.9）只在 Dev 上比较，并按 Recall@1、MRR、nDCG@5、同分优先 RRF 选择配置。配置写入 `evaluation/v076_hybrid_config.json` 后才运行 held-out Test。

RRF 使用 `1/(k+rank)`，BM25 与 Semantic 候选按 canonical `case_id` 去重。Weighted ablation 使用 rank normalization，不直接相加 BM25 与 cosine score。当前不使用 Query Expansion、LLM、Cross-Encoder、query-specific rule 或 synonym boost。

## 结果与边界

最终 Dev 选择为 weighted semantic alpha=0.8。Held-out Test（10 queries）结果为：BM25 Recall@1/MRR/nDCG@5 = 1.0000/1.0000/0.9613，Semantic = 0.9000/0.9500/0.9693，Hybrid = 1.0000/1.0000/0.9920。Hybrid 在 Test 上相对 Semantic 修复 1 条 Top1 miss，未破坏原本正确的 Top1。

Full-30 descriptive 结果为：BM25 Recall@1/MRR/nDCG@5 = 0.8667/0.9222/0.9059，Semantic = 0.9333/0.9667/0.9613，Hybrid = 0.9667/0.9833/0.9718。V0.7.5 Semantic Full-30 Recall@1 已为 0.9333，因此 Hybrid 的提升上限很小；Full-30 仅为配置冻结后的 descriptive result，不是独立测试集。

结果详见 `evaluation/v076_hybrid_metrics.json`、`evaluation/v076_hybrid_results.json` 和 summary。失败/分歧审计保留了 8 条代表性记录，供后续判断是否需要 reranker；本阶段不实现 reranker。

延迟按串行 BM25 retrieval + Semantic retrieval + fusion 计算；没有并行实现时不宣称并行。
